# Data Analytics Internship Projects – DecodeLabs

## Overview
This repository contains the successful completion of three Data Analytics internship projects assigned by DecodeLabs. The projects demonstrate practical skills in data cleaning, exploratory data analysis (EDA), and SQL-based data analysis using a real-world transactional dataset.

---

# Project 1: Data Cleaning & Preparation

## Objective
Prepare a raw dataset for analysis by identifying and resolving data quality issues.

## Tasks Performed
- Identified missing values
- Handled null values in the CouponCode column
- Checked for duplicate records
- Verified duplicate Order IDs
- Validated data formats (dates, numeric values, and text fields)
- Prepared a clean dataset for analysis

## Skills Demonstrated
- Data Cleaning
- Data Validation
- Data Preparation
- Python (Pandas)

## Outcome
The dataset was cleaned successfully and made ready for further analytical tasks.

# Project 2: Exploratory Data Analysis (EDA)

## Objective
Analyze the dataset to uncover patterns, trends, distributions, and business insights.

## Tasks Performed
- Calculated descriptive statistics
- Analyzed product sales trends
- Examined order status distribution
- Evaluated customer payment preferences
- Identified outliers in transaction values
- Generated business insights from the data

## Key Findings
- Average Order Value ≈ 1054
- Printer was the most ordered product
- Online payment was the most preferred payment method
- Several high-value outlier transactions were identified
- Cancellation and return rates were relatively high

## Skills Demonstrated
- Exploratory Data Analysis
- Descriptive Statistics
- Data Visualization
- Business Insight Generation

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
